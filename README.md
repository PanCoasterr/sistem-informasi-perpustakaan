
# Sistem Informasi Perpustakaan

## Deskripsi Repository
Repository ini digunakan sebagai media penyimpanan dokumentasi Sistem Informasi Perpustakaan. Dokumentasi mencakup gambaran umum sistem, tujuan, pengguna, jenis informasi yang dikelola, serta kebutuhan cloud computing.

## Tujuan Sistem
1. Mempermudah pengelolaan data buku dan anggota perpustakaan.
2. Mempercepat proses peminjaman dan pengembalian buku.
3. Memudahkan pencarian dan pengecekan ketersediaan buku.
4. Mengurangi kesalahan pencatatan administrasi perpustakaan.

## Pengguna Sistem
- Petugas perpustakaan
- Anggota perpustakaan atau mahasiswa
- Administrator sistem

## Isi Repository
Dokumentasi pendukung Sistem Informasi Perpustakaan disimpan dalam folder `Dokumentasi`.

Folder tersebut berisi:
- `01-Deskripsi-Sistem.md`
- `02-Kebutuhan-Cloud.md`
